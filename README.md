生产与建造（暂定名）
====================

单文件网页游戏，纯像素文字风格。

文件说明
  index.html      当前版本（直接双击/浏览器打开即可玩）
  fonts/          像素字体 Zpix
  icons-未使用/   早期素材（32×32 像素图），当前版本未使用
  旧版本/         历史版本，出问题可回退

玩法
  - 场地 5×5 格子，工厂自动产出资源
  - 点空地 → 建造；点/长按工厂 → 详情、拆除
  - 底部：天赋 / 场地 / 设置
  - 顶部：经验条（每产出一个物品 +1 经验）
  - 升级 +1 天赋点，第一个天赋解锁「煤矿」

存档
  浏览器本地存储（localStorage），换浏览器不会带过去。
